# 公开资料学习笔记

> 本文件是公开资料的学习摘要和系统化转译，不保存原文全文。

## 1. CME K线与图表基础

吸收点：

- K线记录一个周期内的开盘、最高、最低、收盘。
- 实体代表开收盘之间的结果，上下影线代表盘中被推动和被拒绝的区域。
- 上影线很长且下影线很短时，说明高位卖压强；下影线很长且上影线很短时，说明低位承接强。
- 同一 K 线在不同位置意义不同：高位长影可能是衰竭，低位长影可能是止跌。

系统转译：

- K线形态必须与 `range_position`、`support_resistance_zone`、`trend_regime` 绑定。
- 任何单根 K 线只生成候选，确认必须来自后续 K 线或结构突破。
- 上下影线需要量化为 `upper_wick_ratio`、`lower_wick_ratio`、`body_ratio`。

## 2. CFA / Fidelity 技术分析框架

吸收点：

- 均线的核心作用是平滑噪声、识别趋势，不是精确预测。
- 短均线上穿长均线可视为动量改善，但震荡行情中容易频繁假信号。
- 趋势指标、动量指标、支撑阻力和图表形态应组合使用，而不是互相替代。

系统转译：

- 均线只做 `trend_filter`，不单独触发强提醒。
- 震荡市里降低均线交叉权重，趋势市里提高回踩均线不破的权重。
- 加入 `ma_whipsaw_risk`，统计最近 N 根 K 线反复穿越均线次数。

## 3. Investopedia K线形态

吸收点：

- 看涨吞没：下跌后出现小阴线 + 大阳线实体覆盖前一实体，代表买方重新控制。
- 锤子线：下跌后出现长下影和小实体，代表低位卖压被承接。
- 射击之星：上涨后出现长上影和小实体，代表高位冲高失败。
- 晨星/黄昏星：三根 K 线构成的情绪转折，比单根 K 线更强调确认。

系统转译：

- `bullish_engulfing` 必须要求前置下跌或回调，不能在高位横盘中机械看多。
- `hammer` 必须处在支撑区或低分位区域，并需要下一根确认。
- `shooting_star` 必须处在阻力区或高分位区域，后续跌破实体低点才确认。
- `morning_star` / `evening_star` 要求三根结构完整，否则只显示“星线候选”。

## 4. 网络实战经验与价格行为

吸收点：

- Pin Bar / 长影线常用于识别关键区域的拒绝，但必须结合支撑阻力、成交量或 VWAP。
- Candle Range Theory 强调累积、诱导/操纵、派发的阶段，但容易被过度解释。
- 多数网络经验都强调“位置 + 确认 + 风险收益比”比形态名称更重要。

系统转译：

- 网络经验只进入 `candidate_rule_pool`，不能直接提高信号等级。
- 对“诱多/诱空/操纵”这类词必须转成可观测条件：假突破、快速回落、反向结构破坏、波动异常。
- 所有网络经验必须用本项目历史数据重新回测。

## 5. WGC 黄金基本面

吸收点：

- 黄金需求由央行、ETF、金饰、金条金币、科技用金等组成。
- 2026 年公开资料继续强调央行购金对黄金长期支撑的重要性。
- 高金价可能压制金饰重量需求，但投资需求和央行需求可能形成结构性支撑。

系统转译：

- 央行购金只影响长线/中线评分，不解释 1m/5m 噪声。
- ETF 流量可做中期资金偏好，连续流入/流出比单日变化更重要。
- 金饰需求下降不必然看空，需要结合投资需求和央行购金。

## 6. CME / CFTC 期货实践

吸收点：

- COMEX GC 是全球黄金期货核心合约之一，成交量和 OI 能反映资金活跃度。
- 价涨量增和 OI 上升通常代表趋势资金参与；价涨量缩可能代表追涨质量下降。
- CFTC COT 非商业净多可代理投机资金情绪，但极端拥挤时反而代表回撤风险。

系统转译：

- `futures_participation_score` 使用成交量、OI、价格方向三者组合。
- `cot_positioning_score` 使用 26 周或 52 周分位，而不是只看绝对值。
- `crowding_risk` 在净多极高且价格滞涨时上调。

## 7. FRED 实际利率与美元框架

吸收点：

- 黄金是无息资产，实际利率上行会提高持有黄金的机会成本。
- 实际利率 = 名义利率 - 通胀预期；市场通常更关注实际利率趋势，而不是 CPI 单点。
- 美元走强通常压制国际金，但危机中可能出现美元和黄金同涨。

系统转译：

- 使用 `DFII10`、`DGS10`、`T10YIE` 构建实际利率和通胀预期解释。
- 使用 `DTWEXBGS` 或 DXY 替代源构建美元压力。
- 使用 `DEXCHUS` 校准国内人民币金价与国际金价差异。

## 8. 书籍体系摘要

### 8.1 Steve Nison 蜡烛图体系

- K线体现多空心理。
- 形态位置比形态名称更重要。
- 反转形态需要确认，不能见形态就反手。

### 8.2 John Murphy 技术分析体系

- 趋势是技术分析的核心。
- 支撑阻力、趋势线、形态、指标应该组合使用。
- 技术分析必须服务交易计划和风险控制。

### 8.3 Al Brooks Price Action

- 每根 K 线都在表达买卖双方力量。
- 趋势、通道、突破、失败突破、二次入场是核心。
- 不要在不清晰的位置频繁交易。

### 8.4 Thomas Bulkowski 统计形态体系

- 形态必须统计失败率、突破后表现和回撤。
- 不能只凭传统说法判断胜率。
- 形态表现依赖市场环境、位置和突破质量。

### 8.5 海龟/趋势跟踪体系

- 先控制风险，再等待趋势。
- ATR/N 可用于波动率归一化仓位。
- 趋势系统靠少数大行情覆盖多次小亏。
