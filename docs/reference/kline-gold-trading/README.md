# K线交易理论与黄金交易实践参考目录

> 生成日期：2026-05-19
>
> 目的：集中保存 K 线交易理论、技术分析体系、黄金交易实践、官方数据源、书籍入口和学习报告，作为后续专家系统、图表识别、风控门控和回测验证的参考资料。

## 文件说明

- `source-index.md`：资料入口、合法获取方式、核心吸收点和入库用途。
- `KLINE_GOLD_TRADING_REPORT.md`：综合学习报告，覆盖 K 线理论、黄金交易实践、实战规则和系统落地建议。
- `sources/public-source-notes.md`：公开资料学习笔记，按官方数据、公开教育页、网络经验和书籍入口分类。
- `library/`：已下载的合法 PDF、TXT、公版电子书和官方数据文件。
- `library/LEGAL_LIBRARY_INDEX.md`：下载资料索引、失败源说明和重跑脚本。

## 合规边界

- 不保存盗版书籍、扫描件、破解 PDF 或未授权全文。
- 对受版权保护的书籍，只记录正版购买/借阅入口、公开简介、核心观点摘要和可执行规则。
- 对官方报告和公开教育页，只保存 URL、摘要、学习笔记和可执行转译，不镜像整站内容。
- 所有交易规则都必须经过回测验证，不把任何单一形态、书籍观点或网络经验直接当成强信号。

## 推荐使用方式

- 先读 `KLINE_GOLD_TRADING_REPORT.md`，建立完整框架。
- 再查 `source-index.md`，定位原始资料入口。
- 后续开发时，把报告中的规则转成字段、阈值、回测样本和前端解释。
