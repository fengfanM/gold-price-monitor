# 黄金贵金属专家知识库到网站模型的集成计划

> 目标：把 `GOLD_PRECIOUS_METALS_EXPERT_KNOWLEDGE_BASE.md` 中的交易理论、风控、技术形态、宏观因子和复盘体系，逐步转化为网站的可执行模型。

## 1. 总体架构

```text
数据源层 -> 因子层 -> 形态层 -> 策略层 -> 风控层 -> 回测层 -> 专家解释层 -> 图表/交易计划 UI
```

### 1.1 数据源层

- 行情：工行积存金、上金所、Yahoo 国际金、美元指数、USDCNY。
- 宏观：FRED 实际利率、美债、通胀预期、VIX、联邦基金利率、资产负债表。
- 资金：COT、GLD、WGC ETF flow、CME OI/volume。
- 事件：CPI、PCE、非农、FOMC、地缘新闻。
- 研报/观点：新闻 RSS、博主/分析师可信度源。

### 1.2 因子层

| 因子组 | 当前能力 | 下一步 |
| --- | --- | --- |
| 利率 | TIPS、10Y 美债 | 增加实际利率变化速度、利率倒挂扩张/收敛 |
| 通胀 | breakeven、CPI 相关规划 | 接事件日历、预期差 |
| 美元 | DXY、USDCNY | 增加美元趋势结构和突破状态 |
| 避险 | VIX、新闻情绪 | 增加事件分级和避险持续性 |
| 资金流 | COT、GLD/WGC、CME | 增加拥挤度、极端分位、资金背离 |
| 贵金属相对强弱 | 金银比规划 | 增加金银比均值回归和套利提示 |

## 2. 评分模型升级路线

### 2.1 当前评分骨架

```text
Score = 技术 + 估值 + 宏观 + 合格信号回测 + 形态 + 专家 + 数据健康 - 风险惩罚
```

### 2.2 下一版推荐权重

| 模块 | 默认权重 | 强信号门控 |
| --- | ---: | --- |
| 技术趋势与动量 | 24% | MA/MACD/BOLL/RSI 至少 2 个不冲突 |
| 多周期结构 | 12% | 1m/5m/15m/60m 不出现严重逆向 |
| 估值水位 | 16% | 当前价处于合理低位或有赔率 |
| 宏观因子 | 18% | 实际利率/美元不能明显压制 |
| 资金流 | 8% | COT/ETF/CME 至少一个不冲突 |
| 形态识别 | 8% | 形态有确认条件和失效价 |
| 选择性回测 | 10% | 合格样本胜率高于基准胜率 |
| 数据健康 | 4% | 关键源失败自动降级 |

### 2.3 强买点硬门槛

- 数据源健康：关键源失败不允许强买点。
- 风险收益比：潜在收益/止损距离必须大于 2:1，优先 3:1。
- 趋势冲突：小周期看多但大周期强空，不允许重仓强提醒。
- 事件风险：重大数据前不追单，除非事件策略专门触发。
- 回测门槛：同类信号样本不足时只能显示观察，不显示“绝佳买点”。


## 4. 多周期共振计划

### 4.1 周期职责

- 1m：执行入场和止损精度。
- 5m：短线形态确认。
- 15m：日内方向判断。
- 60m：大方向过滤。
- 4H/日线：中线波段背景。

### 4.2 共振矩阵

| 周期 | 判断内容 | 输出 |
| --- | --- | --- |
| 1m | 短线动量、支撑反弹 | 入场时机 |
| 5m | 双底/双顶、箱体突破 | 短线确认 |
| 15m | 趋势强弱、BOLL/MACD | 是否顺势 |
| 60m | 大级别压力/支撑 | 是否降仓 |

### 4.3 冲突规则

- 1m 看多、15m/60m 强空：只能轻仓短打。
- 1m 看空、60m 强多：不轻易追空，等待回踩。
- 多周期同向 + 宏观不压制 + 回测支持：提高信号等级。

## 5. 事件驱动模型计划

### 5.1 事件分类

- 高影响：CPI、核心 PCE、非农、FOMC、鲍威尔讲话、突发战争。
- 中影响：PMI、GDP、失业率、零售销售。
- 低影响：常规官员讲话、二线数据。

### 5.2 事件风控规则

- 重大数据前 30 分钟禁止追单。
- 数据后第一波极速波动不立即放大强信号。
- 等待方向确认、回踩或假突破识别后再参与。
- 事件窗口内止损距离使用 ATR 扩展，但仓位必须下降。

## 6. 回测与验证计划

### 6.1 分桶回测

- 按形态：双底、双顶、支撑反弹、阻力压制、吞没等。
- 按周期：1m/5m/15m/60m。
- 按行情状态：趋势、震荡、波动扩张、波动收缩、事件驱动。
- 按宏观背景：实际利率上行/下行、美元强/弱。

### 6.2 指标

- 合格信号胜率。
- 基准胜率。
- 平均收益。
- 盈亏比。
- Profit Factor。
- 最大回撤。
- MAE/MFE。
- 样本数和置信区间。

### 6.3 放大信号条件

- 合格样本数达到最低阈值。
- 胜率高于基准胜率。
- Profit Factor > 1.2。
- 最大回撤可控。
- 最近窗口没有明显失效。

## 7. 风控与交易计划模块

### 7.1 每个信号必须输出

- 入场区。
- 止损位。
- 目标位 TP1/TP2。
- 失效条件。
- 仓位建议。
- 最大可承受亏损。
- 是否适合隔夜。

### 7.2 仓位建议

| 信号等级 | 建议 |
| --- | --- |
| 强买点 | 仅在数据源健康、赔率达标、回测支持时出现 |
| 买点观察 | 可分批、小仓、等待确认 |
| 等待 | 不交易，观察关键价 |
| 风险/卖点 | 禁止追多，考虑止盈或减仓 |

### 7.3 停盘规则

- 单日回撤 5%：停止交易。
- 总回撤 10%：强制复盘。
- 连续 3 次同类信号失败：该信号自动降权。
