# 黄金交易胜率与收益率优化 Master Plan

> 唯一目标：让用户在买卖黄金时更容易避开低质量交易、提高合格信号胜率、提升盈亏比、降低回撤，并把复杂专业体系转化为清晰可执行的交易计划。
>
> 核心理念：顶级交易员不是每次都预测对，而是只在优势足够大时出手，并在错误时快速、低成本退出。

## 1. 当前系统诊断

### 1.1 已具备能力

- 多源行情：工行、上金所、Yahoo 国际金、美元指数、USDCNY。
- 宏观因子：实际利率、美债、通胀预期、VIX、联邦基金利率、央行资产负债表、COT、GLD/WGC、CME 等。
- 策略评分：技术、估值、宏观、回测、专家团、数据源健康综合评分。
- 图表能力：分时、K 线、MA、BOLL、RSI、MACD、高低点、买卖观察标识。
- 形态初版：双底、双顶、支撑反弹、阻力压制、颈线、失效线。
- 回测初版：选择性 Walk-forward、合格信号胜率、基准胜率、Profit Factor、模型可信度。
- 源健康：关键源失败自动降级强信号。
- 知识库：黄金贵金属专家知识库、模型集成计划、Agent 工作流、机器记忆文件。

### 1.2 关键缺口

- 还没有完整交易计划：缺少入场区、止损、止盈、失效条件、仓位建议、风险收益比。
- 还没有多周期共振：1m、5m、15m、60m 的趋势冲突没有系统化。
- 形态库仍偏基础：缺少锤子线、吞没、十字星、头肩、三角、旗形、楔形、MACD/RSI 背离。
- 回测还没有分桶：未按形态、周期、时段、宏观背景、事件窗口拆开验证。
- 事件风险不足：CPI、非农、FOMC、鲍威尔讲话前后没有专门模型。
- 风控还不够执行化：单笔 2% 风险、单日 5% 停盘、总回撤 10% 停盘还未进入 UI 和评分。
- 心理纪律不足：没有防追涨杀跌、防报复交易、防频繁交易的“交易纪律官”。
- 孙子兵法式择机不足：还没有“不战而屈人之兵”的空仓等待、只打优势战、避实击虚、知己知彼框架。

## 2. 顶层优化框架

```text
先判环境 -> 再判方向 -> 再判位置 -> 再判形态 -> 再判赔率 -> 再判风控 -> 最后才允许给交易计划
```

### 2.1 七层门控

| 层级 | 问题 | 通过标准 |
| --- | --- | --- |
| 环境 | 当前是趋势、震荡、事件、流动性稀薄还是假突破高发？ | 行情状态识别明确 |
| 方向 | 宏观、美元、美债、资金流是否支持？ | 至少不明显逆风 |
| 位置 | 当前价是否有估值水位和安全垫？ | 不在短线追高区 |
| 形态 | K 线/分时是否出现可验证结构？ | 有确认条件和失效价 |
| 赔率 | 潜在收益是否大于止损？ | 至少 2:1，强信号优先 3:1 |
| 风控 | 数据源、事件、波动、仓位是否可控？ | 关键源健康，无重大不可控事件 |
| 执行 | 用户应该怎么做？ | 入场、止损、止盈、仓位、失效条件完整 |

## 3. Alpha 提升主线

### 3.1 从“预测价格”升级为“交易优势”

当前很多系统只预测涨跌概率，但真正影响收益的是：

```text
期望收益 = 胜率 × 平均盈利 - 亏损率 × 平均亏损 - 交易成本 - 滑点
```

优化方向：

- 不单独追求高胜率，必须同时追求盈亏比和回撤可控。
- 买点不等于马上买，买点应拆成观察、触发、确认、失效。
- 所有强信号必须有风险收益比测算。

### 3.2 从“单信号”升级为“组合证据链”

强买点必须具备完整证据链：

```text
宏观不逆风 + 估值低位 + 技术止跌 + 形态确认 + 多周期不冲突 + 回测优于基准 + 数据源健康 + 赔率达标
```

### 3.3 从“全市场回测”升级为“同类情景回测”

未来重点不是问“整体胜率多少”，而是问：

- 双底在美盘前有效吗？
- 美元指数上涨时，支撑反弹还有效吗？
- CPI 前 30 分钟出现突破，追单胜率如何？
- 1m 看多但 60m 空头时，收益/回撤是否恶化？

## 4. M5.2 图表形态库升级

### 4.1 K 线形态

| 形态 | 方向 | 交易含义 | 必须输出 |
| --- | --- | --- | --- |
| 锤子线 | 偏多 | 下方承接增强 | 下影比例、实体比例、失效价 |
| 倒锤子 | 候选反转 | 空头衰竭候选 | 后续确认 K |
| 看涨吞没 | 偏多 | 多头反攻 | 吞没强度、确认价 |
| 看跌吞没 | 偏空 | 空头反攻 | 吞没强度、风险价 |
| 十字星 | 中性/转折 | 多空犹豫 | 所处位置决定方向 |
| 启明星 | 偏多 | 三 K 反转 | 右侧确认 |
| 黄昏星 | 偏空 | 高位反转 | 跌破确认 |

### 4.2 结构形态

- 头肩顶/底：颈线、左右肩对称度、目标位。
- 三角收敛：高低点收敛、突破方向、假突破风险。
- 箱体震荡：上沿、下沿、中轴、突破确认。
- 旗形/楔形：趋势延续概率、失效条件。
- MACD/RSI 背离：动量衰竭，不能单独作为强买点。

### 4.3 形态评分公式

```text
PatternScore =
结构完整度 30%
+ 位置质量 20%
+ 动量确认 15%
+ 成交量/代理资金确认 10%
+ 多周期一致性 15%
+ 历史同类胜率 10%
- 事件/宏观逆风惩罚
```

## 5. M6 多周期共振矩阵

### 5.1 周期职责

| 周期 | 职责 | 不允许做什么 |
| --- | --- | --- |
| 1m | 精确入场、止损、右侧确认 | 不允许决定大方向 |
| 5m | 短线形态确认 | 不允许逆 60m 重仓 |
| 15m | 日内方向和趋势强弱 | 不允许忽略事件风险 |
| 60m | 大级别过滤和压力支撑 | 不允许用于极短线追单 |
| 日线/4H | 中线背景 | 不允许精确日内点位 |

### 5.2 共振输出

- 多头共振：1m/5m 止跌，15m 不压制，60m 不强空。
- 空头共振：1m/5m 反弹失败，15m/60m 压制。
- 冲突：小周期多，大周期空，只允许轻仓短打或等待。
- 空仓：周期严重冲突、事件高风险、赔率不足。

### 5.3 共振评分

```text
ConfluenceScore =
1m 15%
+ 5m 25%
+ 15m 30%
+ 60m 30%
- 周期冲突惩罚
```

## 6. M8 交易计划助手

### 6.1 交易计划字段

每次买点观察必须输出：

- 当前动作：空仓等待、观察、分批试探、确认后参与、止盈减仓。
- 入场区：例如 582.1-584.0。
- 触发价：站上颈线/回踩不破/突破确认。
- 止损价：形态失效价或 ATR 止损。
- TP1：前高/中轨/箱体中轴。
- TP2：箱体高度/布林上轨/趋势目标。
- 风险收益比：至少 2:1，强信号优先 3:1。
- 仓位建议：轻仓、正常、禁止追单。
- 失效条件：跌破右底、跌破支撑、美元突破、美债上行等。

### 6.2 仓位模型

```text
建议仓位 = min(
策略等级仓位,
账户风险限额 / 单位止损距离,
事件风险折扣,
数据源健康折扣,
波动率折扣
)
```

### 6.3 风控红线

- 单笔亏损不超过账户 2%。
- 单日回撤 5% 停止交易。
- 总回撤 10% 强制复盘。
- 连续 3 次同类形态失败，该形态自动降权。
- 重大事件前后禁止满仓和追单。

## 7. M9 分桶回测与模型校准

### 7.1 分桶维度

- 形态：双底、双顶、锤子、吞没、头肩、箱体突破。
- 周期：1m、5m、15m、60m。
- 时段：亚盘、欧盘、美盘。
- 行情状态：趋势、震荡、波动扩张、波动收缩。
- 宏观状态：实际利率上行/下行，美元强/弱。
- 事件窗口：数据前、数据后、普通时段。

### 7.2 指标

- 合格信号胜率。
- 基准胜率。
- 平均收益。
- 平均亏损。
- 盈亏比。
- Profit Factor。
- MAE：最大不利波动。
- MFE：最大有利波动。
- 最大回撤。
- 样本数。
- 置信区间。

### 7.3 信号放大规则

只有满足以下条件才能升级为强信号：

- 同类样本数达到阈值。
- 合格信号胜率高于基准。
- Profit Factor > 1.2。
- MAE 不超过止损假设。
- 最近窗口没有明显失效。
- 数据源健康。

## 8. M7 事件驱动与战场时机

### 8.1 事件分类

- S 级：FOMC、非农、CPI、核心 PCE、突发战争。
- A 级：PMI、GDP、失业率、零售销售。
- B 级：常规官员讲话、二线数据。

### 8.2 事件交易规则

- 事件前 30 分钟：不追单，只标记风险。
- 事件后第一波：不立即强买/强卖，先识别假突破。
- 事件后第二阶段：若回踩不破或跌破反抽失败，才给确认信号。
- 事件日：止损距离扩大但仓位下降。

### 8.3 孙子兵法式择机

- 知己知彼：知道当前数据源、模型、周期、仓位是否有优势。
- 避实击虚：不在强阻力和事件乱流里硬上，只打对手防线薄弱的位置。
- 以逸待劳：等待价格回踩支撑、形态确认，而不是追第一波。
- 不战而屈人之兵：没有优势就空仓，空仓是交易系统的一部分。
- 兵贵胜，不贵久：短线交易错了要快退，不拖成长期亏损。

## 9. 心理纪律与反人性模块

### 9.1 交易心理风险识别

网站应识别并提示：

- 追涨杀跌：价格靠近高位且短线涨幅过大。
- 报复交易：连续失败后仍频繁触发交易。
- 扛单倾向：跌破失效价仍试图等待回本。
- 重仓冲动：事件窗口、波动放大时仍想提高仓位。
- 频繁交易：短时间内重复出现低质量信号。

### 9.2 纪律官提示

- “当前不是交易机会，是训练你空仓等待的机会。”
- “这不是低位，是下跌趋势中的第一次反弹，需等待二次确认。”
- “胜率不够时，唯一正确动作是降低频率和仓位。”
- “没有止损的买点，不是买点。”

## 10. UI 终端优化

### 10.1 首页买点观察

新增五段式决策：

```text
1. 当前结论：等待/观察/轻仓试探/确认后参与/风险减仓
2. 为什么：宏观、技术、形态、回测、资金流
3. 怎么做：入场区、触发价、止损、止盈、仓位
4. 什么情况说明错了：失效条件
5. 为什么不能重仓：风险、数据源、事件、样本量
```

### 10.2 图表层

- 形态图层：K 线形态、结构形态、颈线、趋势线。
- 交易计划图层：入场区、止损线、TP1、TP2。
- 概率扇形：未来 5/15/60 分钟区间预测。
- 周期冲突标记：小周期信号被大周期压制时提示。

### 10.3 专家团

新增：

- 兵法择机官：判断是否该空仓等待。
- 心理纪律官：防追高、防扛单、防报复交易。
- 事件交易官：重大数据窗口降级。
- 赔率风控官：只关心风险收益比和仓位。

## 11. Agent 分派计划

### 11.1 pattern-agent

- 目标：扩展 K 线/结构形态库。
- 交付：锤子线、吞没、十字星、头肩、箱体、三角、背离。
- 验收：每个形态有测试、解释、关键价、失效价。

### 11.2 confluence-agent

- 目标：多周期共振矩阵。
- 交付：1m/5m/15m/60m 趋势、动量、形态状态。
- 验收：周期冲突时强信号自动降级。

### 11.3 trade-plan-agent

- 目标：交易计划助手。
- 交付：入场、止损、TP1/TP2、仓位、风险收益比。
- 验收：没有交易计划的信号不能显示强买点。

### 11.4 backtest-agent

- 目标：分桶回测和样本置信度。
- 交付：按形态/周期/时段/事件/宏观状态分桶。
- 验收：强信号必须引用同类桶表现。

### 11.5 event-agent

- 目标：事件窗口风控。
- 交付：CPI、PCE、非农、FOMC、鲍威尔讲话、地缘事件。
- 验收：事件前后信号自动调整仓位和等级。

### 11.6 risk-agent

- 目标：交易纪律和仓位风控。
- 交付：2% 单笔风险、5% 日内停盘、10% 总回撤停盘、连续失败降权。
- 验收：所有交易计划都能计算最大亏损。

### 11.7 psychology-agent

- 目标：投资心理学和纪律约束。
- 交付：追高、扛单、报复交易、频繁交易识别。
- 验收：风险行为会产生明确“不交易”提示。

### 11.8 ui-agent

- 目标：把复杂结论变成小白可执行。
- 交付：五段式决策卡、图表交易计划图层、多周期矩阵、风险仪表盘。
- 验收：用户 10 秒内知道是否该买、怎么买、错了怎么办。

## 13. 最优先执行项

第一优先级不是继续堆指标，而是做 `M11 交易计划助手`。

原因：

- 用户真正需要的是“现在该不该买、怎么买、买错了怎么办”。
- 没有止损、仓位和赔率的买点，会让任何高胜率模型都可能亏钱。
- 交易计划能把知识库、风控、形态、回测和专家团全部串起来。

推荐下一步：

```text
M11.1 新增 TradePlan 类型
M11.2 策略引擎输出入场区/止损/TP1/TP2/仓位/风险收益比
M11.3 前端买点观察展示五段式交易计划
M11.4 强信号必须通过交易计划门控
M11.5 增加单元测试和构建验收
```
